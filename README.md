An end-to-end analytics project analyzing 10,000 banking customer records to identify churn patterns, high-risk customer groups, CLV exposure, revenue risk, and retention priorities.

**Tools used:**

* SQL
* Microsoft Excel
* Pivot Tables
* KPI Cards
* Slicers
* Dashboard Design

**Project outcomes:**

* Analyzed 10,000 customer records
* Identified a 20.37% churn rate
* Built churn-focused customer analysis
* Created an Excel dashboard for business decision-making
* Developed customer retention recommendations
